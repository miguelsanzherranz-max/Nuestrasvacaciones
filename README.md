# Nuestras Vacaciones · Cuaderno de viajes

Reconstrucción **parcial y funcional** a partir del texto recuperado de la web creada en ChatGPT. No es una exportación del proyecto original.

## Incluye
- Página responsive en español, 13 destinos y filtros por continente.
- Mapa interactivo con Leaflet/OpenStreetMap y marcadores aproximados representativos de los destinos (no rutas exactas).
- Selección de 10 extractos de entradas recuperadas.
- Enlace al archivo original: https://nuestrasvacaciones.wordpress.com/
